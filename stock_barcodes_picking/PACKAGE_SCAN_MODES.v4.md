### 2.1 行内字段

| 字段 | 说明 |
|---|---|
| 从 / 至 | 源库位 → 目标库位 |
| 产品名 | 含跟踪类型（序列号/批号/数量） |
| 需求 / 已拣 | 该行需求与已拣数量 |
| **批次/SN 下拉** | **可展开**，列出该行可用的批次/SN；每项显示 `已拣: N`、`✎`、`+1`（可选扫码时） |
| **包裹 chip** | 每个批次/SN 一行：`📦 源包 > 目标包`；两包相同只显示一个 |
| `+N` | 预留数量快捷加，仅可选扫码 |
| ✎ | 行编辑弹窗 |

> 交互要点：批次下拉展开后，**每个批次各自带自己的包裹 chip**（截图元素表已确认）。

## 3. 动作与模式

### 3.1 更多… 菜单（5 项，元素表确认）

| 项 | 类型 | 行为 |
|---|---|---|
| **添加产品** | 弹窗 | 添加不在单据上的产品（沿用现有 `action_add_product_to_picking`） |
| **选择包裹** | 弹窗 | 选已有包裹 → 执行**装包** |
| **移除包裹** | 弹窗 | 列出本单**目标包**（`result_package_id`）→ 选一个 → 二次确认 → 该包裹从本单所有行移除。只清目标包，**不动 quant、不动源包** |
| **扫描拆包** | 进入模式 | 扫产品=该行去掉包裹号；扫包裹=整包去包裹号 |
| **取消拣货** | 进入模式 | 扫产品=该行 `picked=False`；扫包裹=整包取消；预留保留 |

### 3.2 模式状态机

| 模式 | 进入 | 扫产品/SN | 扫包裹 | 退出 |
|---|---|---|---|---|
| `default` | 默认 | 正常拣货 | 整包拣货 | — |
| `pack` | 底栏「装包」 | 正常（不消费） | 装包 | 再点 / ✕ / 切单 / 「返回拣货模式」 |
| `split_scan` | 更多→扫描拆包 | 该行去包裹号 | 整包去包裹号 | ✕ / 切单 / 「返回拣货模式」 |
| `unclaim_scan` | 更多→取消拣货 | 该行 `picked=False` | 整包取消拣货 | ✕ / 切单 / 「返回拣货模式」 |

**默认模式按单据方向**：收货 `incoming` → `pack`；发货 `outgoing` / 调拨 `internal` → `default`。切单重算。

### 3.3 状态反馈

| 状态 | 信息框 | 底栏 |
|---|---|---|
| `default` | `扫包裹 = 整包拣货` | 更多… / 新包裹 / 装包 / 验证 |
| `pack` | `装包中：扫描或选择目标包裹`（蓝框 + ✕） | **返回拣货模式** / 新包裹 / 装包中… / 验证 |
| `split_scan` | `拆包中：扫描产品或包裹，去掉包裹号`（橙框 + ✕） | **返回拣货模式** / … |
| `unclaim_scan` | `取消拣货中：扫描产品或包裹，取消拣货（预留保留）`（橙框 + ✕） | **返回拣货模式** / … |
| 跨单占用 | `SN 0001 仍被 WH/OUT/00053 预留…`（红框） | 顶栏下「确认拣货」按钮 |

### 3.4 写入规则

**扫描拆包（split_scan）**
- 扫产品：该产品在本单**已装包**的行 `result_package_id = False`；`package_id` 源包不动；`picked` 不动。
- 扫包裹：该包裹在本单所有行 `result_package_id = False`。
- 0 行匹配 → 报错「没有可拆的明细」。

**取消拣货（unclaim_scan）**
- 扫产品/包裹：对应行 `picked = False`；**不删行、不动预留**。
- 0 行匹配 → 报错「没有可取消的拣货」。

**装包（pack）**
- 沿用 `_bind_to_package`：已拣未装包的行绑到目标包裹。

**移除包裹（弹窗）**
- 弹窗内容：本单的**目标包**（`result_package_id` 去重），显示 `包裹名 · 行数 · 数量`。
- 选中一个 → 提示「将把 XXXXXXX 从本单 N 行中移除，确定？」→ 确认后执行。
- 写入：该包裹在本单**所有行**（含未拣）`result_package_id = False`。
- `package_id`（源包）**保留**；quant 不动，见 Q11。
- 执行后信息框提示「已从 N 行移除包裹 XXXXXXX」。

> **与官方 `stock.package.unpack()` 的区别**（v4.3 补充）
>
> | 维度 | 本模块「移除包裹」 | 官方 `unpack()` |
> |---|---|---|
> | 对象 | 本单的 `stock.move.line` | `stock.quant`（库存实物） |
> | 实现 | 清 `result_package_id` | 立刻生成库存移动，把 quant 移出包裹 |
> | 影响 quant | 否 | 是（不可逆） |
> | 影响本单行 | 是 | **否**（行仍引用原包裹，易致验证异常） |
> | 适用 | 拣货中调整包装归属 | 包裹管理页、货未被预留时 |
>
> 因此扫码页不做实物解包；需要实物解包时，在包裹表单点官方「拆包」按钮。
